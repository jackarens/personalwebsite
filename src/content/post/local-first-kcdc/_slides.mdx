
## `indexes`

```ts
indexes: {
  categories: {
    jsonPointer: "/_indexes/category",
  },
},
```

<ul class="p-4">
	<Fragment as="li">`jsonPointer` picks the value out of each stored document</Fragment>
	<Fragment as="li">Set these up front — adding one later reindexes the cache</Fragment>
</ul>
</Slide>

<Slide>
## `pullInterval`

```ts
// Default is 60s. We watch the project document for an rcVersion
// change instead, and pull only when there is something to pull.
pullInterval: null,
```

<ul class="p-4">
	<Fragment as="li">Polling every 60s costs a request per client per minute</Fragment>
	<Fragment as="li">We already had a realtime listener on the project doc</Fragment>
	<Fragment as="li">`null` means: only pull when *we* say so</Fragment>
</ul>
</Slide>

<Slide>
## `pushDelay`

```ts
// Mutations made within 1000ms of each other go out
// as a single push request.
pushDelay: 1000,

requestOptions: { minDelayMs: 0 },  // don't throttle pulls
```

<ul class="p-4">
	<Fragment as="li">Typing in a cell fires a mutation per keystroke</Fragment>
	<Fragment as="li">The client stays instant either way — this is purely server load</Fragment>
</ul>
</Slide>

<Slide>
## `schemaVersion`

```ts
schemaVersion: "2",

rep.onUpdateNeeded = async (reason) => {
  showBlockingUpdateDialog();
```

<ul class="p-4">
	<Fragment as="li">Sent on every push and pull — old clients get rejected</Fragment>

<Slide>
## Our First Version

```ts
// Looks fine. Clobbers every field you didn't send.
updateElement: async (tx, { elementId, elementData }) => {
  return tx.set(`projects/${projectId}/elements/${elementId}`,
                elementData);
},
```

<ul class="p-4">
	<Fragment as="li">`tx.set` replaces the whole value, and has no dot-notation</Fragment>
	<Fragment as="li">Ana saves a due date, Ben saves a cost, Ben's write erases Ana's</Fragment>
</ul>
</Slide>

<Slide>
## What We Do Instead

```ts
updateElement: async (tx, args) => {
  const element = await tx.get(
    `projects/${projectId}/elements/${args.elementId}`);

  // Replicache set() supports neither partial updates nor dot
  // notation, so we rebuild the object with lodash set().
  const update = cloneDeep(element);
  Object.entries(args.elementData).forEach(([key, value]) => {
    set(update, key, value);   // key: "fields.abc123.value"
  });

  return tx.set(`projects/${projectId}/elements/${args.elementId}`,
                update);
},
```

</Slide>

## Conflict Resolution

**Our answer: last write wins, per field**

<ul class="p-4">
	<Fragment as="li">Every change is logged with who, what, and when</Fragment>
	<Fragment as="li">Users can roll back any change</Fragment>
	<Fragment as="li">The log doubles as our audit trail</Fragment>
</ul>

<Fragment as="div">
	<Callout type="note" title="Why this works for us">
		Collisions are rare, and undo beats a merge dialog
	</Callout>
</Fragment>
</Slide>

## Deleting Is Its Own Mutator

```ts
// JSON has no undefined, and the server needs
// an explicit FieldValue.delete().
deleteElementProperty: async (tx, args) => {
  const update = cloneDeep(await tx.get(key(args)));
  unset(update, args.propertyKey);
  return tx.set(key(args), update);
},
```

<Fragment as="div">
	<Callout type="caution" title="Archive, don't destroy">
		`deleteElement` sets `status: "archived"`. Rollback needs the row.
	</Callout>
</Fragment>

## Handling Replays on the Server

```ts
function push(clientId, mutations) {
  for (const m of mutations) {
    // Replays are normal, not exceptional.
    if (m.id <= lastMutationID(clientId)) continue;
    if (!hasPermission(clientId, m)) continue;

    applyMutation(m);
    recordMutationProcessed(clientId, m.id);
  }
}
```

## Pull, With Permissions and Paging

```ts
function pull(cookie) {
  // 🔒 only sync what this client may see
  const changes = filterByPermission(
    client, getChangesSince(cookie));
  // 📄 cap the batch; client pulls again while hasMore
  const page    = changes.slice(0, MAX_BATCH);
  const hasMore = changes.length > MAX_BATCH;

  return { patches: buildPatches(page), hasMore,
           cookie: hasMore ? page.at(-1).version
                           : currentCookie() };
}
```

## Update Contention

**Bulk backend writes fail under contention**

<ul class="p-4">
	<Fragment as="li">The client never hits this — it retries at will</Fragment>
	<Fragment as="li">Local changes can't contend with anything</Fragment>
	<Fragment as="li">Server-side bulk updates absolutely can</Fragment>
</ul>

<Fragment as="div">
	<Callout type="tip" title="Solution: queue + backoff">
		Failed updates retry until they land, or get logged and dropped
	</Callout>
</Fragment>
</Slide>

<Slide>
## Queue + Retry

```ts
async function processQueueItem(item) {
  const { retryCount: n, maxRetries } = item;
  try {
    await applyUpdates(item.projectId, item.updates);
  } catch (err) {
    if (isContentionError(err) && n < maxRetries) {
      await queue.enqueue(
        { ...item, retryCount: n + 1 },
        2 ** n * 1000);      // backoff
    } else {
      await logFailedUpdate(item, err);
    }
  }
}
```
